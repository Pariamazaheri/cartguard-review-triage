# Data provenance

Raw archives are downloaded by the source module and ignored by Git. Source metadata records the Kaggle dataset identifier and version; run metadata records the actual file hashes. Reports contain derived research artifacts, not a redistribution of the full raw dataset.

[Women’s E-Commerce Clothing Reviews](https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews), version 1, Kaggle CC0 metadata. Required source fields: Clothing ID, Review Text, Age, Recommended IND, Division Name, Department Name and Class Name. Rating and Positive Feedback Count are deliberately excluded from predictors. Target 1 means non-recommendation. `example_reviews.csv` is fictional and for inference demonstration only.
